# Классификатор ДУЧП 2-го порядка

Определение типа дифференциального уравнения в частных производных 2-го порядка
и замены переменных, приводящей его к каноническому виду.

Теория и все эталонные примеры взяты из материалов курса, лежащих в корневой папке курса:
`1.pdf` (лекция 1), `Примеры к лекции 1.pdf`, `2.pdf`. Все команды ниже запускаются из папки `lab1_canonical`.

Нужен Python 3 с `sympy` и `matplotlib`.

## Как определяется тип

Для **n переменных** уравнение `Σ aᵢⱼ·u_xᵢxⱼ + F = 0` задаёт характеристическую
квадратичную форму `Q(λ) = Σ aᵢⱼ λᵢλⱼ`. Метод Лагранжа приводит её к виду
`Σ βᵢ μᵢ²` заменой `μ = Cλ`; тогда `P = C⁻¹`, а замена переменных в самом
уравнении есть `ξ = Pᵀx`. Тип читается по набору `β`:

* все `βᵢ ≠ 0`, знаки разные → гиперболический;
* есть `βᵢ = 0` → параболический;
* все `βᵢ ≠ 0` одного знака → эллиптический.

Правильность приведения проверяется тождеством `PᵀAP = diag(β)` — его считает
сама программа, поле `verified`.

Для **двух переменных** работает и метод характеристик: дискриминант
`D = a₁₂² − a₁₁a₂₂` характеристического уравнения
`a₁₁dy² − 2a₁₂dxdy + a₂₂dx² = 0` даёт `D > 0` — гиперболический,
`D = 0` — параболический, `D < 0` — эллиптический.

Если коэффициенты зависят от `x, y`, то и `D` зависит от точки: плоскость
разбивается на области постоянства знака `D`, и в каждой уравнение приводится
к своему каноническому виду (задание C).

## Про «встроенные функции»

Готовые классификаторы ДУЧП и решатели не используются. Реализованы вручную:
метод Лагранжа, обращение матрицы, правило классификации по сигнатуре, решение
характеристического уравнения, разбиение плоскости на области, разбор
выражений `a(x,y)` в виджете.

`sympy` используется только как калькулятор точной арифметики — дроби, радикалы,
производные, первообразные, корни многочлена; `matplotlib` — только для рисования.
