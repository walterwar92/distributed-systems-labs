# 01. ДУЧП 2-го порядка: определения и классификация

Источник: лекция 1 (`1.pdf`, слайды 2–6, 12, 14, 18), лекция 2 (слайд 24).

## Определения

- **ДУЧП 2-го порядка** — уравнение, которое кроме независимых переменных и искомой функции содержит её частные производные (старший порядок — второй):
  F(x₁,…,xₙ, u, u_{x₁},…,u_{xₙ}, u_{x₁x₁}, …) = 0.
- **Линейное** — линейно относительно u и всех её производных:
  Σ a_ij(x)·u_{x_i x_j} + Σ b_i(x)·u_{x_i} + c(x)·u + f(x) = 0.
- **Квазилинейное** — линейно только относительно старших (вторых) производных; коэффициенты при них могут зависеть от x, u, u_x.
- **Однородное** — u ≡ 0 является решением, т. е. нет свободного члена f(x), не зависящего от u. Пример со слайда 3: a(x)u_xx − b(x)u_x + c(x)u² = 0 — однородное, но нелинейное.
- **Решение** — функция, которая при подстановке обращает уравнение в тождество. Проверка — подстановкой (`tools/pde.py check`).
- **Общее решение** ДУЧП 2-го порядка содержит **две произвольные функции**.
- **Суперпозиция** (слайд 6): если u₁,…,u_k — решения линейного однородного уравнения, то Σ C_i·u_i — тоже решение. Линейно независимых частных решений может быть бесконечно много.

### Пример (слайд 4). Является ли φ(x² + y²) решением y·u_x − x·u_y = 0?

u_x = φ′·2x, u_y = φ′·2y ⇒ y·u_x − x·u_y = 2xyφ′ − 2xyφ′ = 0. Тождество ⇒ решение.

### Пример (слайд 5). u_xy = 0

Интегрируем по x: u_y = f(y). Затем по y: u = ∫f(y)dy + ψ(x) = φ(y) + ψ(x), где φ, ψ — произвольные функции.

## Классификация: две переменные (слайды 9, 12, 14)

a₁₁u_xx + 2a₁₂u_xy + a₂₂u_yy + F(x, y, u, u_x, u_y) = 0

**D = a₁₂² − a₁₁a₂₂** — дискриминант характеристического уравнения (8). Определитель матрицы формы Δ = a₁₁a₂₂ − a₁₂² = −D.

| D | Тип | Характеристики | Канонический вид |
|---|---|---|---|
| > 0 | **гиперболический** | два вещественных семейства | v_ξη = F₁ (1-я форма) или v_ξξ − v_ηη = F₂ (2-я форма) |
| = 0 | **параболический** | одно семейство | v_ηη = F₃ |
| < 0 | **эллиптический** | комплексно-сопряжённые | v_ξξ + v_ηη = F₄ |

⚠ **a₁₂ — половина коэффициента при u_xy.** На слайде 6 уравнение записано как A·u_xx + **B**·u_xy + C·u_yy. Тогда a₁₂ = B/2 и D = B²/4 − AC (знак совпадает со знаком B² − 4AC).

**Тип по областям.** Если D = D(x, y), тип определяется в каждой точке: области D > 0, D = 0, D < 0. Пример — уравнение Трикоми y·u_xx + u_yy = 0: D = −y, при y < 0 гиперболическое, на прямой y = 0 параболическое, при y > 0 эллиптическое (подробно в 02). Ещё пример: u_xx + x·u_yy = 0 → D = −x.

Шаблон ответа «определить тип»: выписать a₁₁, a₁₂, a₂₂ → D → знак (или области) → тип.

## Классификация: n переменных (слайды 7, 8, 14)

Σᵢ Σⱼ a_ij·u_{x_i x_j} + F = 0, где A = (a_ij) симметрична: a_ii — коэффициент при u_{x_i x_i}, a_ij = a_ji = ½·(коэффициент при u_{x_i x_j}), i ≠ j.

Характеристическая квадратичная форма Q(λ) = Σ a_ij·λ_i·λ_j приводится к Σ β_i·μ_i² (метод — в 03). Типы (слайд 14):

| β_i | Тип |
|---|---|
| все β_i ≠ 0 и одного знака | эллиптический |
| все β_i ≠ 0, но не одного знака | гиперболический |
| есть β_i = 0, ненулевые одного знака | параболический |
| есть нули и разные знаки | ни один из трёх типов лекции |

Быстрые проверки (дополнение, закон инерции):
- числа положительных, отрицательных и нулевых β_i равны числам положительных, отрицательных и нулевых собственных значений A;
- все корни характеристического многочлена симметричной A вещественны, поэтому **число положительных собственных значений = числу перемен знака** в коэффициентах det(λI − A) (правило Декарта здесь точное); число нулевых — кратность корня λ = 0;
- критерий Сильвестра: все угловые миноры > 0 ⇒ эллиптический; знаки миноров чередуются, начиная с «−» ⇒ эллиптический;
- det A = 0 ⇒ есть нулевое β ⇒ параболический или вне классификации.

## Основные уравнения матфизики (лекция 2, слайд 24)

| Уравнение | Тип | Почему |
|---|---|---|
| u_tt = a²Δu + f | гиперболический | в (x, t): a₁₁ = −a², a₂₂ = 1 ⇒ D = a² > 0 |
| u_t = a²Δu + f | параболический | вторых производных по t нет ⇒ β_t = 0, остальные одного знака |
| Δu = f | эллиптический | все β = 1 |

## Две канонические формы гиперболического уравнения (слайд 18)

- 1-я: u_xy = 0; 2-я: u_xx − u_yy = 0.
- Из 1-й во 2-ю: ξ = x + y, η = x − y ⇒ u_xy = v_ξξ − v_ηη.
- Обратно: p = ξ + η, q = ξ − η ⇒ v_ξξ − v_ηη = 4·w_pq.
