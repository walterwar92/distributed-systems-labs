# 02. Канонический вид: две переменные, метод характеристик

Источник: лекция 1 (слайды 9–17), методичка §1 и §3.

## Алгоритм

Дано: a₁₁u_xx + 2a₁₂u_xy + a₂₂u_yy + b₁u_x + b₂u_y + c·u + f = 0.

1. Выписать a₁₁, **a₁₂ = ½·(коэффициент при u_xy)**, a₂₂. Найти D = a₁₂² − a₁₁a₂₂ → тип (при переменных коэффициентах — по областям).
2. Характеристическое уравнение (7): a₁₁dy² − 2a₁₂dx·dy + a₂₂dx² = 0 ⇔ a₁₁(y′)² − 2a₁₂y′ + a₂₂ = 0 ⇒ **dy/dx = (a₁₂ ± √D)/a₁₁**.
   Если a₁₁ = 0: dx·(a₂₂dx − 2a₁₂dy) = 0 ⇒ x = C и a₂₂x − 2a₁₂y = C.
3. Проинтегрировать и получить общие интегралы φ(x, y) = C — это характеристики.
4. Выбрать новые переменные (слайд 13):
   - D > 0: ξ = φ₁(x, y), η = φ₂(x, y);
   - D = 0: ξ = φ(x, y), η — любая функция с якобианом J = ξ_xη_y − ξ_yη_x ≠ 0 (обычно η = x или η = y);
   - D < 0: интеграл φ ± iψ = C ⇒ ξ = φ (Re), η = ψ (Im).
5. Пересчитать производные (формулы ниже), подставить, привести подобные, разделить на коэффициент при старшей производной.
6. При переменных коэффициентах выразить коэффициенты через ξ, η (обратная замена).
7. Если просят «упростить», убрать младшие производные (см. 04).
8. Проверка: `python -X utf8 tools/pde.py canonical "<уравнение>" --vars "x y"`.

## Формулы замены u(x, y) = v(ξ, η) (слайд 10, методичка стр. 1)

- u_x = v_ξ·ξ_x + v_η·η_x
- u_y = v_ξ·ξ_y + v_η·η_y
- u_xx = v_ξξ·ξ_x² + 2v_ξη·ξ_xη_x + v_ηη·η_x² + v_ξ·ξ_xx + v_η·η_xx
- u_xy = v_ξξ·ξ_xξ_y + v_ξη·(ξ_xη_y + ξ_yη_x) + v_ηη·η_xη_y + v_ξ·ξ_xy + v_η·η_xy
- u_yy = v_ξξ·ξ_y² + 2v_ξη·ξ_yη_y + v_ηη·η_y² + v_ξ·ξ_yy + v_η·η_yy

Для u(x, y, z) и новых ξ, η, ω всё аналогично (методичка стр. 1), например
u_xy = v_ξξξ_xξ_y + v_ηηη_xη_y + v_ωωω_xω_y + v_ξη[ξ_xη_y + ξ_yη_x] + v_ξω[ξ_xω_y + ξ_yω_x] + v_ηω[η_xω_y + η_yω_x] + v_ξξ_xy + v_ηη_xy + v_ωω_xy.

Коэффициенты нового уравнения ā₁₁v_ξξ + 2ā₁₂v_ξη + ā₂₂v_ηη + b̄₁v_ξ + b̄₂v_η + c·v + f = 0:
- ā₁₁ = a₁₁ξ_x² + 2a₁₂ξ_xξ_y + a₂₂ξ_y²
- ā₁₂ = a₁₁ξ_xη_x + a₁₂(ξ_xη_y + ξ_yη_x) + a₂₂ξ_yη_y  (⚠ на слайде 10 у первого слагаемого потерян множитель a₁₁)
- ā₂₂ = a₁₁η_x² + 2a₁₂η_xη_y + a₂₂η_y²
- b̄₁ = a₁₁ξ_xx + 2a₁₂ξ_xy + a₂₂ξ_yy + b₁ξ_x + b₂ξ_y; b̄₂ — то же с η
- инвариант: ā₁₂² − ā₁₁ā₂₂ = J²·(a₁₂² − a₁₁a₂₂), поэтому замена не меняет тип.

## Постоянные коэффициенты: готовые замены (a₁₁ ≠ 0)

k₁,₂ = (a₁₂ ± √D)/a₁₁ — корни a₁₁k² − 2a₁₂k + a₂₂ = 0; характеристики y − kx = C. Младшие коэффициенты: b̄₁ = b₁ξ_x + b₂ξ_y, b̄₂ = b₁η_x + b₂η_y.

| Тип | Замена | Старшая часть после замены |
|---|---|---|
| D > 0 | ξ = y − k₁x, η = y − k₂x | −(4D/a₁₁)·v_ξη |
| D = 0 | ξ = y − kx (k = a₁₂/a₁₁), η = x | a₁₁·v_ηη |
| D < 0 | k = α ± iβ, α = a₁₂/a₁₁, β = √(−D)/a₁₁: ξ = y − αx, η = βx | (−D/a₁₁)·(v_ξξ + v_ηη) |

## Разобранные примеры (всё проверено sympy)

### Пример 1 — методичка §3 (параболический), с исправлением

u_xx − 2u_xy + u_yy + 9u_x + 9u_y − 9u = 0.

- a₁₁ = 1, a₁₂ = −1, a₂₂ = 1 ⇒ D = 1 − 1 = 0 ⇒ **параболический**.
- (y′)² + 2y′ + 1 = 0 ⇒ y′ = −1 ⇒ y + x = C. Берём ξ = x + y, η = x.
- ξ_x = 1, ξ_y = 1, η_x = 1, η_y = 0.
- u_x = v_ξ + v_η, u_y = v_ξ; u_xx = v_ξξ + 2v_ξη + v_ηη; u_xy = v_ξξ + v_ξη; u_yy = v_ξξ.
- Подстановка: (v_ξξ + 2v_ξη + v_ηη) − 2(v_ξξ + v_ξη) + v_ξξ + 9(v_ξ + v_η) + 9v_ξ − 9v =
  **v_ηη + 18v_ξ + 9v_η − 9v = 0**.

⚠ В методичке (стр. 5) написано 10v_ξ вместо 18v_ξ — арифметическая ошибка (9 + 9 = 18). Из-за неё неверен и §4 (см. 04).

### Пример 2 — гиперболический, постоянные коэффициенты

u_xx − 5u_xy + 6u_yy = 0: a₁₂ = −5/2, D = 25/4 − 6 = 1/4.
k₁,₂ = −5/2 ± 1/2 = −2, −3 ⇒ ξ = y + 2x, η = y + 3x ⇒ −v_ξη = 0 ⇒ **v_ξη = 0**.
Общее решение: **u = F(y + 2x) + G(y + 3x)**.

### Пример 3 — эллиптический

u_xx + 2u_xy + 5u_yy − 32u = 0: a₁₂ = 1, D = 1 − 5 = −4.
y′ = 1 ± 2i ⇒ y − x ∓ 2ix = C ⇒ ξ = y − x, η = 2x ⇒ 4v_ξξ + 4v_ηη − 32v = 0 ⇒ **v_ξξ + v_ηη − 8v = 0**.
Методичка (§2, другой метод, ξ = x, η = (y − x)/2) даёт v_ξξ + v_ηη − 32v = 0. Оба ответа верны: канонический вид определён с точностью до масштаба переменных.

### Пример 4 — a₁₁ = 0

u_xy + u_yy = 0: a₁₁ = 0, a₁₂ = ½, a₂₂ = 1, D = ¼ > 0.
dx·(dx − dy) = 0 ⇒ x = C, x − y = C ⇒ ξ = x − y, η = x ⇒ **v_ξη = 0** ⇒ u = F(x − y) + G(x).

### Пример 5 — уравнение Трикоми y·u_xx + u_yy = 0 (слайды 15–17)

a₁₁ = y, a₁₂ = 0, a₂₂ = 1 ⇒ D = −y.

**а) y < 0 (гиперболический).** y·dy² + dx² = 0 ⇒ dx = ±√(−y)·dy ⇒ x ± (2/3)(−y)^{3/2} = C.
ξ = x + (2/3)(−y)^{3/2}, η = x − (2/3)(−y)^{3/2}; ξ_x = η_x = 1, ξ_y = −√(−y), η_y = √(−y), ξ_yy = 1/(2√(−y)) = −η_yy.
y·u_xx + u_yy = 4y·v_ξη + (v_ξ − v_η)/(2√(−y)). Делим на 4y, учитываем (−y)^{3/2} = ¾(ξ − η):
**v_ξη − (v_ξ − v_η)/(6(ξ − η)) = 0**.
⚠ На слайде 15 стоит «+» — ошибка знака (проверено вручную и sympy).

**б) y = 0 (параболический).** Уравнение сразу имеет вид u_yy = 0.

**в) y > 0 (эллиптический).** (2/3)y^{3/2} ± ix = C ⇒ ξ = x, η = (2/3)y^{3/2}; η_y = √y, η_yy = 1/(2√y).
y·v_ξξ + y·v_ηη + v_η/(2√y) = 0, делим на y, y^{3/2} = 3η/2:
**v_ξξ + v_ηη + v_η/(3η) = 0** (на слайде 17 верно).

### Пример 6 — переменные коэффициенты

x²u_xx − y²u_yy = 0 (x, y > 0): D = x²y² > 0; dy/dx = ±y/x ⇒ y/x = C, xy = C.
ξ = y/x, η = xy ⇒ −4y²·v_ξη + (2y/x)·v_ξ = 0 ⇒ **v_ξη − v_ξ/(2η) = 0**.

## Типичные ошибки

- взять a₁₂ равным всему коэффициенту при u_xy (нужна половина);
- ошибиться в знаке: y′ = (**+**a₁₂ ± √D)/a₁₁, потому что в уравнении (7) стоит −2a₁₂dx·dy;
- в параболическом случае выбрать η, зависимую от ξ (J = 0);
- при переменных коэффициентах не выразить коэффициенты через ξ, η;
- арифметика при приведении подобных (как в методичке) — всегда проверять `tools/pde.py`.
