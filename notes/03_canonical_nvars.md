# 03. Канонический вид: n переменных, метод квадратичной формы

Источник: лекция 1 (слайды 7–8), методичка §2 (стр. 2–4). Метод работает только при **постоянных** коэффициентах при старших производных (или в фиксированной точке).

## Алгоритм

1. Матрица A (симметричная): a_ii — коэффициент при u_{x_i x_i}; **a_ij = a_ji = ½·коэффициент при u_{x_i x_j}**. Вектор b — коэффициенты при u_{x_i}.
2. Характеристическая форма Q(λ) = Σ a_ij·λ_i·λ_j. На практике: коэффициент при u_{x_i x_i} идёт к λ_i², а коэффициент при u_{x_i x_j} — к λ_iλ_j.
3. **Метод Лагранжа** — выделение полных квадратов:
   - если есть λ₁²: собрать все слагаемые с λ₁ в a₁₁(λ₁ + …)², остаток уже без λ₁; повторить для следующих;
   - если квадратов нет (например, λ₁λ₂ − 2λ₁λ₃ + λ₂λ₃): подставить λ₁ = (ν₁ + ν₂)/2, λ₂ = (ν₁ − ν₂)/2, остальные λ_k = ν_k. Тогда λ₁λ₂ = (ν₁² − ν₂²)/4 и квадраты появятся.
4. Записать Q = Σ β_i·μ_i², μ = M·λ, β_i ∈ {1, −1, 0}. Числовые множители загоняются под квадрат: 2ν₃² = (√2·ν₃)².
   Если β = 0, добавить недостающую μ_k (любую, лишь бы M была невырожденной).
5. P = M⁻¹, то есть λ = P·μ.
6. **Новые переменные ξ = Pᵀx.** Обозначим B = Pᵀ; обратно x = Mᵀξ.
7. Пересчёт при линейной замене ξ_k = Σ_i B_ki·x_i:
   u_{x_i} = Σ_k B_ki·v_{ξ_k},  u_{x_i x_j} = Σ_{k,l} B_ki·B_lj·v_{ξ_k ξ_l}.
   Итог: **Σ β_k·v_{ξ_k ξ_k} + Σ b̄_k·v_{ξ_k} + c·v + f(Mᵀξ) = 0**, где b̄ = B·b (так как B·A·Bᵀ = diag β).
8. Тип — по β (см. 01). Проверка: B·A·Bᵀ = diag(β) и `python -X utf8 tools/pde.py canonical "<уравнение>" --vars "x y z"`.

Замена не единственна. У инструмента может получиться другая P (например, с другим знаком столбца), но набор β (тип) и вид «Σβ·v_ξξ + младшие» не меняются.

## Пример 1 — методичка стр. 2–3 (гиперболический)

u_xy − 2u_xz + u_yz + u_x + ½u_y = 0.

- A = [[0, ½, −1], [½, 0, ½], [−1, ½, 0]], b = (1, ½, 0).
- Q = λ₁λ₂ − 2λ₁λ₃ + λ₂λ₃. Квадратов нет, поэтому λ₁ = (ν₁ + ν₂)/2, λ₂ = (ν₁ − ν₂)/2, λ₃ = ν₃:
  Q = ¼ν₁² − ¼ν₂² − ν₁ν₃ − ν₂ν₃ + ½ν₁ν₃ − ½ν₂ν₃
    = ¼[ν₁² − 2ν₁ν₃ + ν₃²] − ¼ν₃² − ¼[ν₂² + 6ν₂ν₃ + 9ν₃²] **+** 9/4·ν₃²
    = {½(ν₁ − ν₃)}² − {½(ν₂ + 3ν₃)}² + {√2·ν₃}².
  ⚠ В методичке в промежуточной строке «− 9/4ν₃²» — опечатка, нужно «+»; итог верный. Там же μ₁ = ½(λ₁ + λ₂ − ν₃) — опечатка, должно быть λ₃.
- μ₁ = ½(λ₁ + λ₂ − λ₃), μ₂ = ½(λ₁ − λ₂ + 3λ₃), μ₃ = √2·λ₃ ⇒ Q = μ₁² − μ₂² + μ₃², β = (1, −1, 1) ⇒ **гиперболический**.
- M = [[½, ½, −½], [½, −½, 3/2], [0, 0, √2]], P = M⁻¹ = [[1, 1, −√2/2], [1, −1, √2], [0, 0, √2/2]].
- ξ = Pᵀx: **ξ = x + y, η = x − y, ω = −(√2/2)x + √2·y + (√2/2)z**.
- ξ_x = 1, ξ_y = 1, ξ_z = 0; η_x = 1, η_y = −1, η_z = 0; ω_x = −√2/2, ω_y = √2, ω_z = √2/2.
- u_x = v_ξ + v_η − (√2/2)v_ω; u_y = v_ξ − v_η + √2·v_ω;
  u_xy = v_ξξ − v_ηη − v_ωω + (√2/2)v_ξω + (3√2/2)v_ηω;
  u_xz = −½v_ωω + (√2/2)v_ξω + (√2/2)v_ηω;
  u_yz = v_ωω + (√2/2)v_ξω − (√2/2)v_ηω.
- b̄ = B·b = (1 + ½, 1 − ½, −√2/2 + √2/2) = (3/2, ½, 0).
- **v_ξξ − v_ηη + v_ωω + (3/2)v_ξ + ½v_η = 0.**

## Пример 2 — методичка стр. 3–4 (эллиптический)

u_xx + 2u_xy + 5u_yy − 32u = 0.

- Q = λ₁² + 2λ₁λ₂ + 5λ₂² = (λ₁ + λ₂)² + (2λ₂)² ⇒ μ₁ = λ₁ + λ₂, μ₂ = 2λ₂, β = (1, 1) ⇒ **эллиптический**.
- M = [[1, 1], [0, 2]], P = M⁻¹ = [[1, −½], [0, ½]], B = Pᵀ = [[1, 0], [−½, ½]].
- **ξ = x, η = (y − x)/2**; ξ_x = 1, ξ_y = 0, η_x = −½, η_y = ½.
- u_xx = v_ξξ − v_ξη + ¼v_ηη; u_xy = ½v_ξη − ¼v_ηη; u_yy = ¼v_ηη.
- **v_ξξ + v_ηη − 32v = 0.** (Через характеристики получается v_ξξ + v_ηη − 8v = 0 — это тоже верно, см. 02.)

## Пример 3 — параболический (β с нулём)

u_xx + 2u_xy + u_yy + u_zz = 0.

- Q = λ₁² + 2λ₁λ₂ + λ₂² + λ₃² = (λ₁ + λ₂)² + λ₃². Добавляем μ₃ = λ₂ (β₃ = 0), чтобы M была невырожденной.
- M = [[1, 1, 0], [0, 0, 1], [0, 1, 0]], P = M⁻¹ = [[1, 0, −1], [0, 0, 1], [0, 1, 0]], B = Pᵀ = [[1, 0, 0], [0, 0, 1], [−1, 1, 0]].
- ξ = x, η = z, ω = y − x ⇒ u_xx = v_ξξ − 2v_ξω + v_ωω, u_xy = v_ξω − v_ωω, u_yy = v_ωω, u_zz = v_ηη.
- **v_ξξ + v_ηη = 0**, β = (1, 1, 0) ⇒ **параболический**.

## Матричная форма (так считает `tools/pde.py`)

Симметричный метод Гаусса: A ← EᵀAE, T ← TE. Шаги: перестановка переменных, «λ_j → λ_j + λ_k», если на диагонали нули, затем обнуление строки и столбца k. В конце TᵀAT = diag(d), нормировка на √|d_i|, P = T·diag(1/√|d_i|).
