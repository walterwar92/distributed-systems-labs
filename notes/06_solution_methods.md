# 06. Справочник методов решения

В лекциях 1–2 этого пока нет, но в следующих темах почти наверняка появится. Формулы стандартные (Смирнов т. 2, Тихонов–Самарский), **каждая проверена sympy**. Страницы указаны по Смирнову (стр. PDF = стр. книги).

## 1. Линейное уравнение 1-го порядка (Смирнов §2, п. 22–24, с. 66–75)

- a(x,y)·u_x + b(x,y)·u_y = 0 → характеристическая система dx/a = dy/b → первый интеграл φ(x,y) = C → **u = F(φ(x,y))**.
- Квазилинейное a·u_x + b·u_y = c(x,y,u): dx/a = dy/b = du/c → два интеграла φ₁(x,y,u) = C₁, φ₂(x,y,u) = C₂ → Φ(φ₁, φ₂) = 0.
- n переменных: Σ a_i·u_{x_i} = 0 → dx₁/a₁ = … = dxₙ/aₙ → n − 1 интегралов → u = F(φ₁, …, φ_{n−1}).
- Пример (лекция 1, слайд 4): y·u_x − x·u_y = 0 → dx/y = dy/(−x) → x·dx + y·dy = 0 → **u = F(x² + y²)**.

## 2. Общие решения простейших уравнений 2-го порядка

| Уравнение | Общее решение |
|---|---|
| u_xy = 0 | F(x) + G(y) |
| u_ηη = 0 | F(ξ) + η·G(ξ) |
| u_ξη + c·u_ξ = 0 | e^{−cη}·F(ξ) + G(η) |
| u_ηη + c·u_η = 0 | F(ξ) + G(ξ)·e^{−cη} |
| u_ξη = f(ξ, η) | ∬f dξ dη + F(ξ) + G(η) |
| a₁₁u_xx + 2a₁₂u_xy + a₂₂u_yy = 0, D > 0 | F(y − k₁x) + G(y − k₂x), k₁,₂ = (a₁₂ ± √D)/a₁₁ |
| то же, D = 0 | F(y − kx) + x·G(y − kx), k = a₁₂/a₁₁ |
| 2a₁₂u_xy + a₂₂u_yy = 0 (a₁₁ = 0) | F(x) + G(a₂₂x − 2a₁₂y) |
| u_tt = a²u_xx | F(x − at) + G(x + at) — бегущие волны |

**Задача Коши для гиперболического уравнения с постоянными коэффициентами** (например, данные на y = 0):
1. u = F(y − k₁x) + G(y − k₂x);
2. u(x,0) = φ: F(−k₁x) + G(−k₂x) = φ(x); u_y(x,0) = ψ: F′(−k₁x) + G′(−k₂x) = ψ(x);
3. продифференцировать первое по x, решить систему относительно F′, G′, проинтегрировать, подставить аргументы;
4. проверить `tools/pde.py check`.

Пример: u_xx + 2u_xy − 3u_yy = 0, u(x,0) = 3x², u_y(x,0) = 0 ⇒ k = 3, −1 ⇒ u = F(y − 3x) + G(y + x) ⇒ **u = 3x² + y²**.

## 3. Формула Даламбера (Смирнов п. 177, с. 517–520)

Задача: u_tt = a²u_xx, −∞ < x < ∞, t > 0; u(x,0) = φ(x), u_t(x,0) = ψ(x).

**u(x,t) = [φ(x − at) + φ(x + at)]/2 + (1/(2a))·∫_{x−at}^{x+at} ψ(s) ds.**

- С источником f(x,t) (п. 187, с. 549; принцип Дюамеля) добавляется (1/(2a))·∫₀ᵗ ∫_{x−a(t−τ)}^{x+a(t−τ)} f(s,τ) ds dτ.
- Смысл: волна вправо F(x − at) плюс волна влево G(x + at). Решение в точке (x, t) зависит от данных на отрезке [x − at, x + at] (характеристический треугольник).
- Инструмент: `python -X utf8 tools/pde.py dalembert "sin(x)" "0" --a a`.

## 4. Полубесконечная струна x > 0 (Смирнов п. 178, с. 520–524)

- **Закреплённый конец** u(0,t) = 0 — нечётное продолжение φ и ψ. При x ≥ at работает обычная формула; при 0 ≤ x < at:
  u = [φ(x + at) − φ(at − x)]/2 + (1/(2a))·∫_{at−x}^{x+at} ψ(s) ds.
- **Свободный конец** u_x(0,t) = 0 — чётное продолжение. При 0 ≤ x < at:
  u = [φ(x + at) + φ(at − x)]/2 + (1/(2a))·[∫₀^{at−x} ψ ds + ∫₀^{x+at} ψ ds].
- От закреплённого конца волна отражается «перевёрнутой», от свободного — без переворота.

## 5. Метод Фурье для ограниченной струны (Смирнов п. 179–181, с. 524–534)

Задача: u_tt = a²u_xx, 0 < x < l; u(0,t) = u(l,t) = 0; u(x,0) = φ, u_t(x,0) = ψ.

1. u = X(x)·T(t) ⇒ X″/X = T″/(a²T) = −λ.
2. X″ + λX = 0, X(0) = X(l) = 0 ⇒ λ_n = (πn/l)², X_n = sin(πnx/l), n = 1, 2, …
3. T_n″ + (aπn/l)²·T_n = 0 ⇒ T_n = A_n·cos(aπnt/l) + B_n·sin(aπnt/l).
4. **u = Σ_{n≥1} [A_n·cos(aπnt/l) + B_n·sin(aπnt/l)]·sin(πnx/l)**, где
   A_n = (2/l)·∫₀ˡ φ(x)·sin(πnx/l) dx,  B_n = (2/(aπn))·∫₀ˡ ψ(x)·sin(πnx/l) dx.

Частоты ω_n = aπn/l. n-я гармоника — стоячая волна с n − 1 узлами внутри (0, l).

### Задача Штурма–Лиувилля X″ + λX = 0 на (0, l)

| Граничные условия | λ_n | X_n | n |
|---|---|---|---|
| X(0) = 0, X(l) = 0 | (πn/l)² | sin(πnx/l) | 1, 2, … |
| X′(0) = 0, X′(l) = 0 | (πn/l)² | cos(πnx/l) | 0, 1, … (λ₀ = 0, X₀ = 1) |
| X(0) = 0, X′(l) = 0 | (π(2n+1)/(2l))² | sin(π(2n+1)x/(2l)) | 0, 1, … |
| X′(0) = 0, X(l) = 0 | (π(2n+1)/(2l))² | cos(π(2n+1)x/(2l)) | 0, 1, … |
| X(0) = 0, X′(l) + hX(l) = 0 | корни tg(√λ·l) = −√λ/h | sin(√λ_n·x) | 1, 2, … |

Нормы: ∫₀ˡ sin²(πnx/l) dx = ∫₀ˡ cos²(πnx/l) dx = l/2 при n ≥ 1.

## 6. Вынужденные колебания (Смирнов п. 182, с. 534–537)

u_tt = a²u_xx + f(x,t), граничные и начальные условия нулевые: u = Σ T_n(t)·sin(πnx/l), где
f_n(t) = (2/l)·∫₀ˡ f(x,t)·sin(πnx/l) dx, T_n″ + ω_n²·T_n = f_n, T_n(0) = T_n′(0) = 0 ⇒
**T_n(t) = (1/ω_n)·∫₀ᵗ f_n(τ)·sin ω_n(t − τ) dτ**, ω_n = aπn/l.

Общая смешанная задача = эта задача + свободные колебания (п. 5) + неоднородные граничные условия (05, §4).

## 7. Уравнение теплопроводности (Смирнов §20, с. 628–648)

- **Бесконечный стержень** (п. 214, с. 629): u_t = a²u_xx, u(x,0) = φ:
  **u = (1/(2a√(πt)))·∫_{−∞}^{∞} φ(s)·exp(−(x − s)²/(4a²t)) ds** (ядро — гауссиана, его интеграл равен 1).
  С источником f добавляется ∫₀ᵗ ∫ f(s,τ)·exp(−(x − s)²/(4a²(t − τ)))/(2a√(π(t − τ))) ds dτ.
- **Полубесконечный** (п. 215, с. 634): при u(0,t) = 0 ядро [e^{−(x−s)²/(4a²t)} − e^{−(x+s)²/(4a²t)}]/(2a√(πt)), s ∈ (0, ∞); при u_x(0,t) = 0 — со знаком «+».
- **Ограниченный стержень** (п. 216, с. 639), u(0,t) = u(l,t) = 0:
  **u = Σ C_n·e^{−(aπn/l)²t}·sin(πnx/l)**, C_n = (2/l)·∫₀ˡ φ·sin(πnx/l) dx.
  - Теплоизолированные концы (u_x = 0): u = C₀/2 + Σ C_n·e^{−(aπn/l)²t}·cos(πnx/l), C_n = (2/l)∫₀ˡ φ·cos(πnx/l) dx; при t → ∞ u → C₀/2, среднему значению φ.
  - Постоянные температуры концов u(0,t) = T₁, u(l,t) = T₂: u = T₁ + (T₂ − T₁)x/l + v, где v решает задачу с нулевыми условиями и начальными данными φ − T₁ − (T₂ − T₁)x/l.
- Полезно: ∫_{−∞}^{∞} e^{−s²} ds = √π; erf z = (2/√π)·∫₀^z e^{−s²} ds.

## 8. Уравнение Лапласа (Смирнов §19, с. 592–627)

- Свойства гармонических функций (п. 204, с. 599): значение в центре шара равно среднему по сфере; максимум и минимум достигаются на границе (если u ≠ const).
- Лапласиан (п. 131, с. 377):
  - полярные координаты: Δu = u_rr + u_r/r + u_φφ/r²;
  - цилиндрические: то же + u_zz;
  - сферические: (1/r²)(r²u_r)_r + (1/(r² sin θ))(sin θ·u_θ)_θ + (1/(r² sin²θ))·u_φφ.
- Фундаментальные решения: ln(1/r) на плоскости, 1/r в пространстве.
- **Задача Дирихле в круге** r < R, u(R,φ) = f(φ) (п. 205–206, с. 603–610):
  u = a₀/2 + Σ (r/R)ⁿ·(a_n·cos nφ + b_n·sin nφ), a_n = (1/π)∫₀^{2π} f(t)·cos nt dt, b_n = (1/π)∫₀^{2π} f(t)·sin nt dt.
  Интеграл Пуассона: u(r,φ) = (1/(2π))·∫₀^{2π} f(t)·(R² − r²)/(R² − 2Rr·cos(t − φ) + r²) dt.
  - вне круга (R/r)ⁿ вместо (r/R)ⁿ;
  - кольцо R₁ < r < R₂: A₀ + B₀·ln r + Σ[(A_n rⁿ + B_n r⁻ⁿ)·cos nφ + (C_n rⁿ + D_n r⁻ⁿ)·sin nφ].
- **Прямоугольник** 0 < x < a, 0 < y < b, u = 0 на трёх сторонах, u(x,b) = f(x):
  u = Σ c_n·[sh(πny/a)/sh(πnb/a)]·sin(πnx/a), c_n = (2/a)·∫₀ᵃ f·sin(πnx/a) dx.
- Уравнение Пуассона Δu = f: u = частное решение + гармоническая функция. Например, при f = const в круге частное решение f·r²/4.

## 9. Ряды Фурье (Смирнов гл. VI, с. 435–512)

- На (−l, l) (п. 158, с. 449): f ~ a₀/2 + Σ(a_n·cos(πnx/l) + b_n·sin(πnx/l)),
  a_n = (1/l)∫_{−l}^{l} f·cos(πnx/l) dx, b_n = (1/l)∫_{−l}^{l} f·sin(πnx/l) dx.
- На (0, l) (п. 157, с. 444): по синусам (нечётное продолжение) b_n = (2/l)∫₀ˡ f·sin(πnx/l) dx; по косинусам (чётное) a_n = (2/l)∫₀ˡ f·cos(πnx/l) dx.
- Теорема Дирихле (п. 155, с. 440): в точке разрыва сумма ряда равна [f(x − 0) + f(x + 0)]/2.
- Равенство Парсеваля (п. 169, с. 488): (1/l)∫_{−l}^{l} f² dx = a₀²/2 + Σ(a_n² + b_n²).
- Готовые интегралы (проверены):
  - ∫₀ˡ sin(πnx/l) dx = l(1 − (−1)ⁿ)/(πn)
  - ∫₀ˡ x·sin(πnx/l) dx = (−1)ⁿ⁺¹·l²/(πn)
  - ∫₀ˡ x·cos(πnx/l) dx = l²((−1)ⁿ − 1)/(πn)²
  - ∫₀ˡ x(l − x)·sin(πnx/l) dx = 2l³(1 − (−1)ⁿ)/(πn)³
  - ∫₀ˡ x²·sin(πnx/l) dx = (−1)ⁿ⁺¹·l³/(πn) + 2l³((−1)ⁿ − 1)/(πn)³
- Инструмент: `python -X utf8 tools/pde.py sine "x*(l-x)" --l l`.

## 10. Телеграфное уравнение (Смирнов §18, с. 571–591)

LC·u_tt + (LG + RC)·u_t + RG·u = u_xx. Замена u = e^{−μt}·v, μ = (LG + RC)/(2LC), даёт
v_tt = (1/LC)·v_xx + ((RC − LG)/(2LC))²·v.

Линия без искажений (RC = LG): v_tt = v_xx/(LC) — сигнал идёт со скоростью 1/√(LC) без искажения формы и затухает как e^{−(R/L)t}.
