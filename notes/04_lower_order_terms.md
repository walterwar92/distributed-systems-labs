# 04. Устранение младших производных

Источник: методичка §4 (стр. 5–6), с исправлением ошибки. Метод работает при **постоянных** коэффициентах, обычно уже после приведения к каноническому виду.

## Идея

Замена u = w·e^{λξ + μη} (в методичке v = g·e^{αξ+βη}). Экспонента сокращается, а λ, μ подбираются так, чтобы обнулить коэффициенты при первых производных. Если одну из производных убрать нельзя (параболический случай), обнуляют коэффициент при самой функции.

Производные (после деления на e^{λξ+μη}):
- u_ξ → w_ξ + λw, u_η → w_η + μw
- u_ξξ → w_ξξ + 2λw_ξ + λ²w, u_ηη → w_ηη + 2μw_η + μ²w
- u_ξη → w_ξη + μw_ξ + λw_η + λμw

## Готовые ответы

| Канонический вид | λ, μ | Результат |
|---|---|---|
| u_ξξ + u_ηη + b₁u_ξ + b₂u_η + cu = f | λ = −b₁/2, μ = −b₂/2 | w_ξξ + w_ηη + (c − (b₁² + b₂²)/4)·w = f·e^{−(λξ+μη)} |
| u_ξξ − u_ηη + b₁u_ξ + b₂u_η + cu = f | λ = −b₁/2, μ = **+**b₂/2 | w_ξξ − w_ηη + (c − b₁²/4 + b₂²/4)·w = f·e^{−(λξ+μη)} |
| u_ξη + b₁u_ξ + b₂u_η + cu = f | λ = −b₂, μ = −b₁ | w_ξη + (c − b₁b₂)·w = f·e^{−(λξ+μη)} |
| u_ηη + b₁u_ξ + b₂u_η + cu = f, b₁ ≠ 0 | μ = −b₂/2, λ = (b₂²/4 − c)/b₁ | w_ηη + b₁·w_ξ = f·e^{−(λξ+μη)} |

**Общая формула** (n переменных): Σa_ij·u_ij + Σb_i·u_i + c·u = f, u = w·e^{α·x}:
- новые коэффициенты: b̄ = 2Aα + b, c̄ = αᵀAα + bᵀα + c;
- при невырожденной A: α = −½A⁻¹b ⇒ b̄ = 0, c̄ = c − ¼·bᵀA⁻¹b.

В ответе вернуться к исходной функции: u(x, y) = w(ξ(x,y), η(x,y))·exp(λξ(x,y) + μη(x,y)).

## Пример — методичка §4, исправленный

После §3 (см. 02) правильный канонический вид такой: v_ηη + 18v_ξ + 9v_η − 9v = 0, где ξ = x + y, η = x.

v = g·e^{αξ+βη}:
- g_ηη + 2βg_η + β²g + 18(g_ξ + αg) + 9(g_η + βg) − 9g = 0
- g_ηη + (2β + 9)g_η + 18g_ξ + (β² + 18α + 9β − 9)g = 0
- 2β + 9 = 0 ⇒ **β = −9/2**
- β² + 18α + 9β − 9 = 81/4 − 81/2 − 9 + 18α = 18α − 117/4 = 0 ⇒ **α = 13/8**
- **g_ηη + 18g_ξ = 0**, v = g·e^{13ξ/8 − 9η/2}, т. е. u = g(x + y, x)·e^{(13y − 23x)/8}.

⚠ В методичке из-за ошибки 10v_ξ получилось α = 2,925 и g_ηη + 10g_ξ = 0. Внутри методички это согласовано, но исходная арифметика неверна. Правильный ответ проверен sympy (`tools/pde.py lower`).

## Ещё примеры (тесты `tools/test_pde.py`)

- u_xx + u_yy + 2u_x − 4u_y + u = 0 ⇒ u = w·e^{−x + 2y} ⇒ **w_xx + w_yy − 4w = 0**.
- u_xy + 2u_x + 3u_y + u = 0 ⇒ u = w·e^{−3x − 2y} ⇒ **w_xy − 5w = 0**.
