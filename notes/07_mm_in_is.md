# 07. «Математические модели в ИС» — конспект презентации и дополнения

Файл `Математические модели в ИС.pdf`: 13 слайдов студенческой презентации, источник — Тихонов–Самарский. Формул почти нет, это обзор применений.

## Волновое уравнение — гиперболический тип (слайды 2–4)

u_tt = c²Δu:
- ∂²u/∂t² — «ускорение», с которым меняется состояние системы;
- c² — квадрат скорости распространения волны (на слайде «скорость распространения волны (фазовая скорость)»);
- Δu — «кривизна» функции в пространстве: насколько значение в точке отличается от соседних.

В ИС это основа систем, которые считают распространение механических, звуковых и электромагнитных возмущений. Примеры:
- **сейсморазведка** — обработка отражённых волн, построение 3D-моделей земной коры, поиск месторождений нефти и газа;
- **игровые движки** — процедурная генерация и симуляция поверхности воды;
- **акустическое ПО** — архитектурная акустика (концертные залы), активное шумоподавление.

## Уравнение теплопроводности — параболический тип (слайды 5–7)

Описывает эволюцию системы к равновесию: размытие, сглаживание, диффузию информации. Процесс необратим во времени (энтропия растёт).
- математическая модель **гауссова размытия** (Gaussian blur);
- **анизотропная диффузия** — шумоподавление с сохранением контуров.

Примеры:
- **фильтры изображений** — сглаживание, удаление высокочастотного шума в редакторах и системах машинного зрения, предобработка данных для нейросетей;
- **финтех** — модель Блэка–Шоулза (ценообразование опционов) сводится к уравнению теплопроводности, используется для оценки рисков;
- **тепловой анализ в САПР/CAE** — температурные поля в процессорах, печатных платах, деталях под нагрузкой.

## Уравнение Лапласа — эллиптический тип (слайды 8–10)

Система в устойчивом (равновесном) состоянии, решения — гармонические функции, переменной времени нет. Уравнение используют, когда нужно найти баланс или по известным значениям на границе заполнить область максимально гладко, без скачков.

Примеры:
- **компьютерная графика** — распределение света между поверхностями (глобальное и точечное освещение) в 3D;
- **картография и ГИС** — гладкие поверхности, интерполяция отсутствующих пространственных данных;
- **электроника (EDA)** — стационарные электрические поля и ёмкости в микросхемах.

## Сравнение (слайд 11)

| Тип | Уравнение | Отношение ко времени | Примеры ИС |
|---|---|---|---|
| гиперболическое | волновое | вторая производная по t | сейсморазведка, игровые движки, акустика |
| параболическое | теплопроводности | первая производная по t | графические редакторы (размытие, фильтры), финтех (опционы) |
| эллиптическое | Лапласа | не зависит (стационарное) | 3D-рендеринг (глобальное освещение), ГИС (интерполяция) |

## Дополнения для ответов на вопросы (формулы проверены sympy)

- **Гауссово размытие — это решение уравнения теплопроводности**: u(·,t) = G_t * u₀, где ядро в ℝⁿ G_t(x) = (4πa²t)^{−n/2}·exp(−|x|²/(4a²t)). Это гауссиана с σ² = 2a²t по каждой оси.
- **Перона–Малик** (анизотропная диффузия): u_t = div(g(|∇u|)·∇u), g убывает, например g = 1/(1 + |∇u|²/K²). На контурах диффузия подавляется.
- **Блэк–Шоулз**: V_t + ½σ²S²V_SS + rSV_S − rV = 0. Замена S = K·eˣ, t = T − 2τ/σ², V = K·e^{−(k−1)x/2 − (k+1)²τ/4}·u(x,τ), k = 2r/σ² даёт **u_τ = u_xx**.
- **Гармоническая интерполяция** (ГИС, inpainting): дискретный лапласиан = 0, то есть каждое значение равно среднему четырёх соседей: u_{i,j} = (u_{i+1,j} + u_{i−1,j} + u_{i,j+1} + u_{i,j−1})/4 (итерации Якоби или Зейделя).
- **Явные разностные схемы**:
  - теплопроводность: u_i^{k+1} = u_i^k + r·(u_{i+1}^k − 2u_i^k + u_{i−1}^k), r = a²τ/h², устойчиво при r ≤ ½ (в 2D при равных шагах r ≤ ¼);
  - волновое уравнение: схема «крест», условие Куранта a·τ/h ≤ 1.
