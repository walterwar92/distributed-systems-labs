Тепловой баланс для участка [x, x+Δx] за время Δt (слайд 17):
Q₁ = S·(k u_x)_x ΔxΔt (поток), Q₂ = F ΔxΔt (источники), Q₃ = cρS·u_t ΔxΔt (нагрев); Q₃ = Q₁ + Q₂.

Вывод для струны (слайды 3–4): ρ dx·u_tt = T₀ sin α|_{x+dx} − T₀ sin α|_x + F dx, где sin α ≈ tg α = u_x (малые колебания).

Проверка телеграфного уравнения: из первого u_xx = −L·i_xt − R·i_x, из второго i_x = −C·u_t − G·u, подставить ⇒ LC·u_tt + (LG+RC)u_t + RG·u = u_xx.

## 2. Типы (слайд 24)

- u_tt = a²Δu + f — **гиперболический**
- u_t = a²Δu + f — **параболический**
- Δu = f — **эллиптический**

## 3. Типы задач (слайд 25)

| Задача | Для каких уравнений | Что задаётся |
|---|---|---|
| Начальная (**Коши**) | гиперболические, параболические | начальное состояние процесса, область — всё пространство |
| **Краевая** | эллиптические | условия на границе области |
| **Смешанная** (начально-краевая) | гиперболические, параболические | начальные условия + условия на границе |

### Задача Коши (слайд 26)

D = ℝⁿ, M = D × (0, ∞), M* = D × [0, ∞).

- **Волновое уравнение**: найти u ∈ C²(M) ∩ C¹(M*) (на слайде C(M*)):
  u_tt = a²Δu + f, (x,t) ∈ M;  u(x,0) = φ(x);  u_t(x,0) = ψ(x), x ∈ D.
- **Теплопроводность**: найти u ∈ C^{2,1}(M) ∩ C(M*):
  u_t = a²Δu + f, (x,t) ∈ M;  u(x,0) = φ(x), x ∈ D.

Число начальных условий равно порядку уравнения по t: два для волнового, одно для уравнения теплопроводности.

### Граничные условия (слайд 27), D ⊂ ℝⁿ ограничена, Γ ∈ C² — граница

| Род | Название | Вид |
|---|---|---|
| I | Дирихле | u\|_Γ = μ(x) |
| II | Неймана | ∂u/∂n\|_Γ = ν(x), n — нормаль (внешняя) |
| III | Робена | (αu + β∂u/∂n)\|_Γ = ω(x), α² + β² ≠ 0 |

### Краевые задачи для уравнения Пуассона (слайд 28)

u ∈ C²(D) ∩ C(D̄), D̄ = D ∪ Γ:
- I рода (Дирихле): Δu = f в D, u = μ на Γ;
- II рода (Неймана): Δu = f в D, ∂u/∂n = ν на Γ;
- III рода: Δu = f в D, αu + β∂u/∂n = ω на Γ.

При f ≡ 0 это задачи для уравнения Лапласа.

Дополнение (стандартный факт): задача Неймана разрешима только при ∫_D f dV = ∮_Γ ν dS, и решение определено с точностью до константы.

### Смешанные задачи (слайды 29–30)

M = D × (0, ∞), M* = D × [0, ∞), M̄ = D̄ × [0, ∞).
- Волновое: u_tt = a²Δu + f в M; u(x,0) = φ, u_t(x,0) = ψ в D; (αu + β∂u/∂n)|_Γ = ω; φ, ψ ∈ C(D̄).
- Теплопроводность: u_t = a²Δu + f в M; u(x,0) = φ в D; (αu + β∂u/∂n)|_Γ = ω; φ ∈ C(D̄).

## 4. Редукция общей задачи (слайд 31)

Задача: u_tt = a²u_xx + f(x,t), 0 < x < l, t > 0; u(x,0) = φ(x); u_t(x,0) = ψ(x); u(0,t) = μ(t); u(l,t) = ν(t).

Ищем u = u₁ + u₂ + u₃ + u₄:

| | u₁ | u₂ | u₃ | u₄ |
|---|---|---|---|---|
| уравнение | u_tt = a²u_xx | u_tt = a²u_xx | u_tt = a²u_xx | u_tt = a²u_xx **+ f** |
| u(x,0) | **φ(x)** | 0 | 0 | 0 |
| u_t(x,0) | **ψ(x)** | 0 | 0 | 0 |
| u(0,t) | 0 | **μ(t)** | 0 | 0 |
| u(l,t) | 0 | 0 | **ν(t)** | 0 |

Дополнение (обычный приём): чтобы сделать граничные условия однородными, берут w(x,t) = μ(t) + (x/l)(ν(t) − μ(t)). Тогда u = v + w, где
v_tt = a²v_xx + f − w_tt, v(x,0) = φ − w(x,0), v_t(x,0) = ψ − w_t(x,0), v(0,t) = v(l,t) = 0.
Для теплопроводности то же самое с f − w_t. При постоянных μ, ν функция w — стационарное решение.

## 5. Физический смысл граничных условий (дополнение: Тихонов–Самарский)

В лекции даны только общие виды I–III рода. Это шаблоны для задач «поставьте задачу».

**Струна / стержень** (конец x = 0; для x = l знак при u_x меняется на противоположный):
| Физика | Условие |
|---|---|
| конец жёстко закреплён | u(0,t) = 0 (I) |
| конец движется по закону μ(t) | u(0,t) = μ(t) (I) |
| свободный конец (стержень без нагрузки; кольцо струны скользит без трения) | u_x(0,t) = 0 (II) |
| к концу приложена сила F(t) | струна: T₀u_x(0,t) = −F(t); стержень: ES·u_x(0,t) = −F(t). На конце x = l: T₀u_x(l,t) = F(t) (II) |
| упругое закрепление (пружина жёсткости κ) | u_x(0,t) − h·u(0,t) = 0, h = κ/T₀ (или κ/(ES)); на x = l: u_x + h·u = 0 (III) |

**Теплопроводность** (стержень):
| Физика | Условие |
|---|---|
| на конце поддерживается температура μ(t) | u(0,t) = μ(t) (I) |
| в торец x = 0 входит поток q(t) | −k·u_x(0,t) = q(t); в торец x = l: k·u_x(l,t) = q(t) (II) |
| торец теплоизолирован | u_x = 0 (II) |
| теплообмен по Ньютону со средой температуры θ(t) | x = 0: u_x − H(u − θ) = 0; x = l: u_x + H(u − θ) = 0, H = h/k > 0 (III) |
| боковой теплообмен со средой | u_t = a²u_xx − b²(u − θ) (в уравнении) |

## 6. Шаблон ответа «поставьте задачу»

1. Неизвестная функция и её смысл: u(x,t) — …
2. Уравнение с областью: 0 < x < l, t > 0.
3. Начальные условия: для волнового два, для теплопроводности одно, для Лапласа их нет.
4. Граничные условия на каждом конце (род I/II/III, физический смысл).
5. Тип уравнения и тип задачи (Коши / краевая / смешанная).
