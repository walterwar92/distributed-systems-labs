# Лабораторная 3. Одномерное уравнение теплопроводности

Выполнили: Садчев Р. В., Богомолов С. С., Стрельцов Б. С.

- **А** — задача Коши на прямой: формула Пуассона или функция Грина, анимация.
- **Б** — полупрямая через функцию Грина, анимация. Вариант граничного условия: **u_x(0,t) = μ(t)·ν(t)**.

| Файл | Назначение |
|---|---|
| `heatlab/kernels.py` | фундаментальное решение G и функции Грина полупрямой G₁, G₂ (метод отражений) |
| `heatlab/line.py` | **задание А**: `HeatLine`: формула Пуассона (адаптивный Симпсон) или свёртка с G на сетке, источник f по Дюамелю |
| `heatlab/halfline.py` | **задание Б**: `HeatHalfLine`: начальное условие + граничный интеграл + источник; II рода (вариант) и I рода |
| `heatlab/numint.py` | свои сетка, формулы Симпсона (обычная и адаптивная), трапеций |
| `heatlab/userfunc.py` | разбор функций, введённых строкой |
| `heatlab/plots.py` | рисование кадров (окно, скрипты, GIF) |
| `app.py` | оконное приложение: вкладки А и Б, готовые примеры, ползунок, анимация, сохранение PNG/GIF |
| `task_a.py`, `task_b.py` | то же из командной строки: диалог или ключи, окно с анимацией и GIF |
| `make_figures.py` | рисунки для отчёта и объяснения, `task_a.gif`, `task_b.gif` |
| `tests/` | 23 теста (сравнение с точными решениями) |
| `report/otchet3.tex` → `otchet3.pdf` | отчёт («быстрый», по пунктам А и Б) |
| `report/explanation3.tex` → `explanation3.pdf` | подробное объяснение каждой формулы и параметра с графиками (для защиты) |

Расчёты без numpy/scipy и без готовых решателей: только модуль `math`; matplotlib и tkinter — для рисования и окна.

## Запуск (из папки `lab3_heat`)

Нужен Python 3 с `matplotlib` и `pillow`.

```bash
python app.py
```

```bash
python task_a.py --a 1 --phi "theta(1-abs(x))" --f 0 --T 2 --xmin -6 --xmax 6 --method poisson
python task_b.py --a 1 --phi "exp(-(x-3)**2)" --mu "-1" --nu "1+sin(4*t)" --T 3 --xmax 8
```

Без ключей программы спрашивают данные по очереди. `--method green` — способ через функцию Грина,
`--kind 1` — условие I рода `u(0,t) = μ·ν` (дополнительно), `--out файл.gif`, `--no-show`.

Тесты и сборка:

```bash
python -m unittest discover -s tests -t .
python make_figures.py
cd report && pdflatex otchet3.tex && pdflatex explanation3.tex
```

## Как вводить функции

`φ` — от `x`; `f` — от `x` и `t`; `μ`, `ν` — от `t`. Доступно: `sin, cos, exp, sqrt, log, abs, maximum, minimum,
theta` (Хевисайд), `sign, pi`; степень `**` или `^`. Примеры: `exp(-(x-3)**2)`, `theta(1-abs(x))`, `1+sin(4*t)`.
