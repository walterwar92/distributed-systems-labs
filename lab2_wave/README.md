## Запуск (из папки `lab2_wave`)

Нужен Python 3 с `matplotlib` и `pillow` (только для графиков и GIF).

Диалог — программа спросит все данные, Enter оставляет значение по умолчанию:

```bash
python task_a.py
```

```bash
python task_b.py
```

То же одной командой:

```bash
python task_a.py --a 1 --phi "exp(-(x-5)**2)" --psi 0 --bc 1 --mu "sin(2*t)" --g "0.3*t" --t 7 --xmax 15
```

```bash
python task_b.py --a 1 --phi "maximum(1-abs(x),0)" --psi 0 --f 0 --T 6 --xmin -8 --xmax 8 --xi 0
```

Вариант группы: `u(0,t) = μ(t) + g(t)` — это `--bc 1` (по умолчанию), функции `--mu` и `--g`.
Дополнительно: `--bc 2` — `u_x(0,t) = μ + g`, `--bc 3` — `u_x(0,t) − h·u(0,t) = μ + g`. Ключи `--out файл` и `--no-show` — сохранить без окна.

Тесты:

```bash
python -m unittest discover -s tests -t .
```

Отчёт:

```bash
cd report && pdflatex otchet2.tex
```

## Как вводить функции

Выражения от `x` (и `t`): `sin, cos, exp, sqrt, abs, maximum, minimum, theta` (Хевисайд), `pi`;
степень `**` или `^`. Примеры: `exp(-(x-5)**2)`, `sin(2*t)`, `maximum(1-abs(x),0)`, `theta(x-1)*theta(2-x)`.

## Про «встроенные функции»

Все вычисления написаны вручную на чистом Python: сетка, формулы трапеций и Симпсона,
линейная интерполяция, функция Грина, сборка решения. `numpy` и `scipy` не используются.
Из стандартной библиотеки взят только `math` (sin, cos, exp и т. п.).
`matplotlib` и `tkinter` — только рисование, сборка GIF и окно приложения.

## Приложение с интерфейсом

```bash
python app.py
```

Две вкладки (А и Б): слева поля ввода, «Построить» или Enter — расчёт, ползунок под графиком — момент времени,
«▶» — анимация, кнопка сохранения — PNG (А) или GIF (Б). Ошибка во введённой функции показывается под кнопками.
